Routes

A route wires one share to one destination. A share may appear in several routes; a destination may be fed by several shares.

Active routes source › target

Create a route pick an existing share and an existing destination

Adding a second route to a share does not duplicate the scan job on the MFP. The box uploads the same file twice, once per route, and deletes the local copy only after every route has confirmed. Use the per-route filter if only some files should take the second route.

Settings

Box-level defaults and the Microsoft 365 tenant connection.

Default rules for new shares

SMB server

SMB1 is off by default for a reason. It has no signing and no encryption, and any device on the LAN can read the scan spool. Lower the floor only for MFPs that cannot speak SMB2, and put those devices on a separate VLAN.

Quarantine & retention

Quarantined files are never deleted automatically while retention is set to Forever. 0 files, 0 B in quarantine.
